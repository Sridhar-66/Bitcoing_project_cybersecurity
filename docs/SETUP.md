# Setup

## Prerequisites

Node.js, npm, Rust, Solana CLI, and Anchor are required only if you want to build/deploy the Solana program.

For the frontend/backend demo:

1. cd backend && npm install && npm run dev
2. In another terminal: cd frontend && npm install && npm run dev

The current prototype uses synthetic transactions so it runs without an RPC key.

For current Anchor/Solana installation instructions, use the official Solana and Anchor documentation.
